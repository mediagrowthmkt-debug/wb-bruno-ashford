Step 1

Install it

First, get the tool. About two minutes.

  • Mac or Linux: curl -fsSL https://claude.ai/install.sh | bash
  • Windows: irm https://claude.ai/install.ps1 | iex. Check it worked with: claude --version
  • This is Claude Code, the tool you talk to. It needs a paid plan (Pro, Max or Team). Free will not run it.
Bruno Ashford · Agents in Claude Code04 / 21
Step 2

Open and talk

You do not type code. You type a sentence.

  • Open your project folder, run claude, then log in.
  • It is a chat. You ask, it does the work. The first run opens your browser to log in.
Bruno Ashford · Agents in Claude Code05 / 21
Step 3

Ask the right way

Better instructions, better results. Say what to do, how, and what a good result looks like.

  • Vague: handle my leads.
  • Clear: reply to each new lead, then book a call.
  • You can also say: explain it before you do it.

Memory

Give it memory

One file makes it remember your business.

  • Ask it to create a CLAUDE.md with your company, tone and rules.
  • Now it remembers all that in every chat. No repeating yourself every time.

The structure

It builds the structure

You never set up folders by hand. It does it.

Step 4

Create the agent

An agent is just one file.

  • Ask: create an agent that replies to new leads.
  • The file holds its name, its job and what it can do. No wizard, just asking is the normal way.

Step 5

How it runs

Built once. It runs when you need it.

  • Call it by name, let it pick itself, or schedule it.
  • Yes, it can run on its own, on a schedule: every morning, every new lead, your choice.

Step 6

Give it skills

A skill is your playbook, saved.

  • Make a folder in .claude/skills with a SKILL.md: a short description, then the steps.
  • Now it runs your process the same way every time. See them with /skills, run one with /skill-name.

Why it stays fast

It only reads a skill in full when it needs it

  • So it can hold many skills and never slow down.

FAQ

Do I need to know how to code to build an AI agent?

No. You describe the job in plain words and the AI writes the setup files itself, from the agent to the skills to the memory file.

What do I need to install?

Claude Code, run with one command in your terminal. It needs a paid Claude plan (Pro, Max or Team). The free plan does not run it.

Can an AI agent run on its own?

Yes. You can call it by name, let it pick itself, or put it on a schedule so it runs every morning or on every new lead.

What is CLAUDE.md?

A single file where the AI stores what it knows about your company, tone and rules, so it remembers all of that in every chat.

What should I automate first?

Start with the most boring task you repeat all week. That is where the hours are hiding, and each agent gives that time back.
