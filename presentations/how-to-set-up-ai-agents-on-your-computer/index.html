Step 1

Install VS Code

First, install VS Code. It is the free app where you'll run everything.

  • Download VS Code from code.visualstudio.com and open its built in terminal.
  • The terminal is just a text box where you type to your computer. Nothing to fear.
Bruno Ashford · AI Agents Setup04 / 15
Step 2

Install Claude Code

Now install Claude Code, the AI that runs on your machine.

  • In the terminal, install Node.js, then paste: npm install -g @anthropic-ai/claude-code. Type claude to start it.
  • This puts the AI on your computer. On the first run it opens your browser to log in once.
  • You need a paid Claude plan (Pro or higher) or an API key. The free chat plan does not include Claude Code.
Bruno Ashford · AI Agents Setup05 / 15
Step 3

Open a folder

Next, point the AI at a folder. That folder is where it works.

  • Open any folder on your computer inside the tool.
  • It reads and edits the real files there. That is what makes it an agent.
Bruno Ashford · AI Agents Setup06 / 15
Step 4

CLAUDE.md, its memory

CLAUDE.md is the file where the AI stores what it knows about you.

  • Say: remember that my business is X. It writes CLAUDE.md itself.
  • Without it, the AI forgets everything between chats.
Bruno Ashford · AI Agents Setup07 / 15
Step 5

Skills, create and adjust

A skill is a saved instruction for a task. With Claude running, you create one just by asking.

  • Say: create a skill that writes a branded PDF. To change it later, say: adjust that skill to add our logo.
  • Claude writes and edits the skill file itself, so the task runs the same way every time.
  • Create: describe the task in plain words. Adjust: tell Claude what to change. Claude updates the file live, no code.
Bruno Ashford · AI Agents Setup08 / 15
Step 6

Agents

An agent is one AI set up for one job. Each agent is its own file.

  • Say what the agent does: write, research, design. It creates the file.
  • Several agents work at the same time instead of one doing everything.

Step 7

Commands

A command is a shortcut you type to run a saved instruction.

  • Say: save this as a command. Then call it any time.
  • You repeat a long task with one word.

Step 8

MCP, connect your apps

MCP connects the AI to apps like Gmail, Drive and your CRM.

  • Say: connect my Gmail, my Drive, my CRM.
  • Now it works inside your real tools, not only in files.

FAQ

Do I need to know how to code to set up AI agents?

No. You talk to the AI in plain words and it writes the setup files itself, from memory to skills to agents.

What do I need to install?

VS Code, the free app where everything runs, and Claude Code. Claude Code needs a paid Claude plan (Pro or higher) or an API key.

What is CLAUDE.md?

The file where the AI stores what it knows about you and your business, so it does not forget between chats.

Does this work with other tools?

Yes. The same setup works in Cursor, Codex CLI and Gemini CLI.
